# Imports

Notebooks and files imported from local launcher links are saved here:

- A single notebook is saved as `untitled.<id>.ipynb` and opened.
- A bundle with a notebook and companion files is saved in its own
  `bundle-<id>` folder, and the chosen notebook is opened.
- A bundle without a notebook is saved in its own `bundle-<id>` folder.
  Nothing is opened, so open the folder from the file browser.

Imports are stored in this browser only. Download anything you want to keep.
